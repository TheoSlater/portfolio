## Overview

Desktop Copilot is an always-on-top AI assistant overlay for your desktop. The goal was to create a distraction-free, keyboard-driven AI interface that lives at your fingertips — without ever leaving your current application.

It routes all AI requests locally via [Ollama](https://ollama.ai), meaning your data stays on your machine. No cloud, no subscriptions, no latency from remote calls.

## Goals and Motivation

I wanted a tool that felt native to my workflow. Existing AI assistants either require switching context (web browser) or are locked to a specific application. Desktop Copilot aims to be OS-level and universal.

Key goals:
- **Zero-latency**: Local inference via Ollama, no round-trips to external servers.
- **Always-on-top**: Overlay that appears on any application with a global shortcut.
- **Minimal UI**: A clean interface that doesn't distract from your work.

## Tech Stack Used

## Features

### Global Shortcut
Summon the copilot from any application using a configurable global keyboard shortcut. The overlay appears on top of whatever you're doing and dismisses just as quickly.

### Local AI Inference
By routing requests to a local Ollama instance, Desktop Copilot achieves near-instant response times for smaller models while keeping all data private.

### Context-Aware
The overlay can optionally capture a screenshot of your current screen to provide context to the model — useful for code review, design feedback, or answering questions about what's on your screen.

## Challenges and How I Dealt with Them

The primary challenge was managing the overlay window lifecycle in Tauri. Tauri's webview windows don't natively support being "always on top" across all desktop environments, and required specific platform-level configuration for macOS, Windows, and Linux.

Another tricky area was the global shortcut registration. On macOS, registering global shortcuts requires accessibility permissions, and handling the permission prompt gracefully was important for a good first-run experience.
